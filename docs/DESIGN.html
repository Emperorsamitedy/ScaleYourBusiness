Do's and Don'ts

Do

  • One amber focal element per screen — action or data line, never both plus decoration.
  • Machine truth in Plex Mono: provenance, field keys, costs, timestamps.
  • Respect the grid and the ten type styles absolutely.
  • Gradients in exactly two places: focal CTA fill, focal card's ember edge.

Don't

  • No crypto-casino: 3D coins, mascots, confetti, pulsing glows, animated gradients.
  • No blue for body text on dark, no blue as a second action color.
  • No drop shadows anywhere — depth is tonal layers, hairlines, light.
  • The light variant is not a second brand: glows off, primary-strong in.
